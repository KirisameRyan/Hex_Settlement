# 幻想城镇 · 游戏设计计划

当前 Godot 原型覆盖从营地起步、魔法研习、春夏季度考核到城镇升阶的流程。

## 体验与核心循环

一场异变把幻想乡的一部分折叠成六边形沙盘。玩家扮演魔理沙，从一间小屋和六名居民起步，发展这片土地，获得足够的力量还原世界。游戏以经营为主，异变通过地图和经营目标表现。每日记录由夜间结算呈现，议事厅负责居民统一调配、入住和招募。

**勘探地块 → 安排作业 → 决定何时派人取货 → 入夜对账 → 建造、招募与研究 → 展开更多地块。** 首次勘探让玩家找到维持营地的资源。稳定产出之后，继续开图可以找到新水源、矿脉和适合扩建的空间。

## 世界规则

| 系统 | 规则 |
| --- | --- |
| 开局与行动 | 一间小屋、六名居民、12 行动点。基地周围一圈已探明。小人实时行动。每花 1 点下达一条采集、勘探或建造命令。持续作业跨天保留，直到改派、耗尽或完工。取货占用空闲居民和路上的时间，花费 0 行动点。 |
| 地块情报 | 地块有迷雾、地形已见、资源已探明三种状态。地形已见的格子比已探明的格子暗，点选后可在地块面板确认状态。草原与林地共用草底，林地由树木辨认。勘探一次查清与已探明格相邻的一格，同时揭开它六个邻格的地形。储量、猎物和矿脉需要抵达后才知道。 |
| 随机地图 | 新局用种子生成 127 格地图，保留固定规模的开局保障：近处有建造空地、木头、岸边水源和山地石料，可在同岸找到猎物。主河从山脉流向湖泊，按两条连接边绘制直流、缓弯和急弯，源头收窄、入湖处展宽。跨河是可选扩张，不计入季度硬条件。 |
| 资源与地形 | 基础资源为木头、石头、水和食物。野生木料、石料和猎物有限。勘探山地后可查明石料储量，再派人分批开采。草原、林地都可能有猎物。林地砍空后变成平原空地，剩余猎物散去。河湖可持续取水，取水员在可抵达的陆地岸边工作。 |
| 现场产出 | 采集者留在作业地。每种资源用一个六边形徽记，数字显示可取数量，外围显示最快完成的一批采集进度。产出时边框闪亮。林地可以同时显示木头和猎物两个徽记。点徽记查看待取量，再决定是否派空闲居民回收。 |
| 取货 | 派遣时锁定界面上这一批的数量，抵达前保持为已预留，抵达后变为手上货物。新产出的资源仍可安排下一趟。白天回到仓库才计入库存。取货卡同时显示预计取到货和回营的时间。 |
| 仓储 | 首轮用 240 格共享库位。派人取货时预留相应库位，并按可用容量限定取货量。剩余物资留在地块。 |
| 白天 | 正常速度下一天至少有 4 分钟白天，首轮用 4 分钟试跑。基础移动约 5 秒跨一格。行动点控制新命令的数量，剩余时间影响作业、取货和地块勘探。用完行动点后仍可取货。 |
| 夜间 | 天黑暂停地图，打开结算。已经拿到货的居民带货回营并入库，尚未拿到货的居民空手回营并解除预留，资源留在原地。结算后可以领取当天已经完成的委托，点「开始下一天」刷新行动点、委托和有空床位时的候选人。 |
| 民生 | 每人每晚消耗 1 口粮和 1 水。农产品、兽肉和鱼肉各自入库、标价，夜间折算成口粮。实际入库和夜间带回的货可用于当晚消耗。短缺时次日采集效率降低 25%，下一晚供应充足后恢复。 |
| 建造与招募 | 木材建住房，完工后增加床位。第一夜起，有空床位时刷新候选人，玩家按特长决定招谁。首轮先试一间住房增加一个床位。 |
| 经验与魔法 | 首次查清地块、建筑完工和领取每日委托奖励都给魔理沙经验。每天三项委托，每项手动领取 3 经验和 2 木头，跳过无惩罚。有待领的奖励时，任务按钮显示红点。魔理沙每次升级获得 1 魔法点和 1 点每日行动上限。研习分生息、行旅、营造三系。绘路符让所在格边缘泛淡蓝光，格内移动耗时减少 35%。初始一枚，研习连路符阵后可同时维持三枚。缩物袋增加 6 点载量。 |
| 通行 | 以整格基准计时，草原与空地 5 秒、河岸 6 秒、林地 6.75 秒、山地 9 秒、河流 8.5 秒、湖泊 10 秒。系统比较可用路线的耗时，跨界后按新格的速度行走。取水在岸边完成，穿过河流到对岸需要一座完工后的木桥。 |
| 镇区 | 镇区从议事厅沿相邻的完工建筑延伸。空地、未完工的新建筑和不相连的据点仍是城外。镇区通行基准为 3 秒每格，营地用压实土路，升到村庄后铺石板。生产地面保留草地和田垄，边缘与相邻地面自然过渡。 |
| 木桥 | 学会绘路符后，可在有相对两岸的已探明河流格下令建桥。基础成本 12 木头、10 石头和 1 行动点，工人从可抵达的岸边施工。完工后河流格可用于通行，该格通行基准降至 5 秒，开放对岸的勘探与派工。 |
| 工坊与渔埠 | 山地可在石料点建采石场，在铁矿脉建矿场。铁匠铺消耗铁矿和木头产出铁件，魔法工房消耗铁件和石头产出修复部件。渔埠在河湖岸边产出鱼肉。作业产出留在地块，派人运回仓库后才能使用。普通设施最多三级，升级在原地施工。 |
| 住所与驿路 | 居民从住宅出工，未入住的居民住在议事厅。驿站可以在可抵达的镇区以外建造，分派空闲居民驻扎。寻路会计入驿路的通行加成，取货员先把货送回仓库，再回住处。 |
| 买卖与行商 | 建成香霖堂后可按库存和收购额度交易。金币独立结算，常设店按天补货。三花定期到访，当天可以收购物资、出售稀有货和勘探工具。交易页暂停白天，悬停查看店主介绍，点击商品选择数量。 |

## 决策与时限

- **一次取完还是赶早。** 一趟取货免费，但会占一个人。等地块多攒一批，能省来回路程。今晚缺粮时，赶在天黑前先取到眼下这一批更重要。取货卡读沿途地形和道路符计算预计耗时。
- **临时采集还是稳定生产。** 采空近处林地能腾地盖住房，也可以把空地留给树场。人口增长增加劳力，同时提高每天的粮水需求。首轮试玩根据四分钟能产出和取回多少批重新调整速率、野生储量和建筑成本。
- **日常任务和季度目标。** 日常任务从当前地图和能力能支持的动作中抽取，例如查清新地块、把食物运入库或建住房。季度发展目标从季度开始就公开，它决定这段经营能否继续。

## 季节、失败与重开

原型每季 5 天。春季第 5 天结束前须达到村庄，夏季第 5 天结束前须达到城镇。未达标时结算页提示失败并提供重开。达标后保留地图与城镇并可继续经营。

议事厅只在夜间核对升阶。达到条件先触发魔理沙短剧情，点击「开始下一天」后更换议事厅贴图，并开放对应阶位的研习资格。村庄需人口 7、已完工住房 1、农田 1。城镇需人口 9、已完工住房 2，另需牧场或木工作坊任一完工。一级住房开局可建。农田在聚落阶段研习，牧场、树场、木工作坊和二级住房在村庄阶段分别研习，大型仓库和三级住房在城镇阶段分别研习。木工作坊使建造或升级少用 4 木头，大型仓库增加 120 库位。
## 剧情与终局

魔理沙既调查异变，也负责经营营地。玩家可以自行勘探发现古驿站，也可以从三花购得线索。派工修复后，附近的迷雾显露地形，古驿站正式开放驻扎。夏季城镇考核通过后，古驿站修好才在入夜结算时解除异变，城镇与地图可以继续经营。

## UI 与美术

已显露的相邻格共用拐角高度，格心保持平面，地块边缘做成窄坡。草地、泥地、裸岩和石板在显示时沿不规则的像素边界互相嵌入，视觉过渡跨越格线。地块选取以实际坡面和六边形范围为准。

Windows 单机，Godot 4。地图使用可平移和缩放的斜俯视镜头，Q / E 分别向两侧旋转 60°，Alt 切换普通和高角度俯视。河流和湖泊处在统一的低水位，草地与山脚之间以浅台阶逐格过渡，相邻格高差上限为 0.26。地图使用纯像素贴图，草地、泥地、石板、水面、剖面侧壁和坡顶材质都采用最近邻采样。树林、山体和草地随季节更换像素贴图。野生动物采用鹿、野兔、野猪和狐狸的 2D 精灵，共用现有猎物规则。建筑、木桥、采石点和施工地基均使用像素贴图。空闲小人留在营地，出勤时用统一纸片精灵。资源图标贯穿地块、库存和结算。

| 界面 | 玩家在这里做什么 |
| --- | --- |
| 地图 | 点格后右侧显示通行耗时、地块加成、产出和在岗居民。六边形指令按钮从选中格上方弹出，周边铭牌暂时隐藏。升级、工作和建造在右侧对应页面确认。点资源徽记显示待取资源和取货指令。升级材料齐备时，建筑铭牌旁浮现动态蓝色箭头。 |
| 屏幕边缘 | 左上日晷显示季节、天数和距入夜的时间，右接魔理沙等级、经验和魔法点，再接行动点、仓库和勘探。浏览地图时右下展示当前季节的魔理沙立绘，地块或议事厅面板打开时替换该位置。左侧为任务、成就和魔法研习。 |
| 议事厅 | 点地图上的议事厅后，可以从建筑旁直接打开居民与调配或仓库内容。居民页可查看五维能力并选空闲居民派工。入住和招募可从议事厅主菜单进入。 |
| 委托板与魔导书 | 独立居中，打开冻结白天，关闭恢复原速度。委托板的每日卡片随进度切换定位、领取和已领取。季度卡片显示人口、住房及设施进度。魔导书按系翻页，左页以连线展示前置关系，右页供阅读和研习。前置未掌握时，后续节点只显示符文。右侧箭头支持点击或向右拖动关闭。 |
| 派工与住房 | 自动派工选择本工作能力最高的空闲居民，名单显示特长及完整能力提示。住房用固定视角手绘精灵和贴地影子呈现，搬迁和升阶读取原有住房状态。 |
| 当日结算 | 地图暂停并显示带回的物资、留在地块上的货、粮水消耗和结余。待领委托可从结算页打开委托板。季度节点在当日账页揭晓达标或失败。资源实际入库时飞向仓库，经验获得时飞向顶栏经验槽，升级提示新增魔法点。 |
| 标题和暂停 | 标题界面左侧提供继续游戏、新游戏、读取存档、设置和退出游戏。新游戏以幻想乡折叠异变开场。白天按暂停键或 Esc 打开局内菜单，恢复时沿用原倍速。魔导书和委托板打开时 Esc 先关闭当前页面。快进时屏幕边缘泛蓝光，可在设置关闭。 |
| 本地存档 | 三个手动槽和一个自动槽。局内暂停菜单可在白天和夜间手动保存，确认进入下一天后自动保存。保留地块、仓库、研习、委托、居民状态和镜头，以及采集、建设、勘查和搬运的剩余进度。标题页继续游戏读取最近存档。 |

## 开发顺序与试玩验证

右上提供暂停、×1/×3 切换和入夜。行动点归零后可以确认跳过白天，通过加速模拟推进现有订单，仍停在夜间结算。建房升级、招募、规划住房沿用同一地图和居民数据。

验证路径包括建住房、勘探获得经验、研习农田、持续产粮与取回、招募第七人、夜间升村庄、通过牧场或作坊升城镇。限时任务及成就保留入口。细化数值、剧情演出、季节环境变化与更多设施另行迭代。
固定地图与任务种子，复现四种取货结果。确认白天送回正常入库，天黑前取到但仍在路上时计入当晚，天黑前尚未取到时保留现场货并返营，途中新增产出留给下一趟。同一账页重复打开和确认均不重复记账。单人和多人同时取货时，预留总量不能超过地块实存。

试玩关注两件事。第一，等玩家取货是否构成「现在派谁、哪批先送」的选择。若玩家每批都得点一次，优先调整单批产量或合并提醒。第二，季度失败能否事先预测。若玩家在失败账页才发现缺目标或不够时间，先改季度面板和进度反馈，再调整门槛。

### 下一阶段

| 顺序 | 玩家能做什么 | 试玩要验证什么 |
| --- | --- | --- |
| 1. 春夏完整试玩与经济调整 | 游玩首个季度，依次体验运回口粮、建住房、招募与研习农田。追踪首次满仓、每日剩余行动点和季度达标时间。 | 春季满仓后，玩家仍有把木料投入建造和把库位留给粮水的选择。春季线路允许优先住房和优先农田两种开局。 |
