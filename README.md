# 幻想城镇 · Fantasy Town

以幻想乡折叠异变为背景的六边形地图经营游戏。玩家扮演魔理沙，带领居民从营地发展成城镇，通过勘探、派工、生产、运输、贸易和遗迹修复展开世界。

当前为 Windows / Godot 4.3 原型，使用 GDScript、斜俯视地图、像素场景素材与角色插画。

## 运行项目

1. 安装 Godot 4.3 Standard。
2. 在 Godot 项目管理器中导入根目录的 project.godot。
3. 等待素材首次导入，按 F5 从标题页开始游戏。

命令行也可以从项目根目录运行 godot --editor --path . 打开编辑器，或使用 godot --path . 开始游戏。项目采用 GL Compatibility 渲染，首次打开时会生成 .godot/ 缓存。

## 当前玩法

- 种子生成六边形地图，包含高低差、河流、支流、湖泊与迷雾。
- 行动点用于下达命令，居民实时执行采集、施工、运输和生产。
- 物资先留在作业地，搬入仓库后用于建造和交易。
- 住宅、驿站、驿路与地形影响出发地点和运输时间。
- 农产品、兽肉、鱼肉分别入库，夜间按口粮结算。
- 普通设施最高三级，包含采石、采矿、锻造、渔业、魔法工房、商店和驿站。
- 香霖堂与来访行商使用货架交易界面，支持库存、收购额度与探矿线索。
- 每日委托、魔法研习、春夏发展考核、古驿站修复和夜间结算。
- 标题、暂停、设置、三个手动存档槽与一个自动存档槽。

数值与经营节奏仍在迭代，秋冬经营事件、成就和限时任务有待完善。详情见 [游戏设计](design/GAME_DESIGN.md)。

## 操作

| 操作 | 按键或入口 |
| --- | --- |
| 选中地块 | 鼠标左键 |
| 平移镜头 | 按住鼠标右键拖动 |
| 缩放镜头 | 滚轮 |
| 旋转镜头 | Q / E，每次 60° |
| 普通 / 高角度俯视 | Alt |
| 回到议事厅 | R |
| 暂停 / 退出子页面 | Esc |
| 工作、升级、建造 | 地块上方六边形按钮，再在右侧确认 |
| 交易 | 选中商店或行商，再点交易 |

## 全建筑展示档

展示档包含全部建筑类型和三级住房。主河的三座桥从上到下为一级、二级和三级。

从项目根目录运行：

```powershell
godot --path . --script showcase/open_showcase.gd
```

它通过游戏现有的校验与存档读取逻辑，直接打开仓库内的 showcase/all-buildings.save。进入游戏后可从暂停菜单选择手动槽保存。

## 项目目录

| 路径 | 内容 |
| --- | --- |
| project.godot | Godot 项目入口 |
| title.tscn / title.gd | 标题与游戏启动 |
| main.tscn / map.gd | 地图、派工、建筑与日夜经营 |
| map_layout.gd / hex_tile.gd | 地图生成与地块表现 |
| campaign.gd / progression_window.gd | 委托与魔法研习 |
| trade_window.gd | 货架交易 |
| session.gd / settlement_snapshot.gd | 设置、存档与旧档迁移 |
| assets/ | 场景、角色、图标、界面和字体 |
| design/ | 游戏设计和美术提示词 |
| showcase/ | 展示档与启动脚本 |

个人设置和游玩存档位于 Godot 的 user://，Windows 默认为 %APPDATA%\FantasyTown。

## 开发与提交

使用 Godot 编辑后，通过标题页和新游戏检查运行情况。修改存档字段时处理旧档迁移。涉及交易和搬运时检查资源预留、扣款与入库的一致性。

提交源素材及其 .import 配置。Godot 的 .godot/ 缓存、导出文件和个人存档由 .gitignore 排除，展示档特意随仓库保留。

本项目是东方 Project 同人原型。角色、世界观、美术和字体的来源见 [素材说明](assets/README.md)。
